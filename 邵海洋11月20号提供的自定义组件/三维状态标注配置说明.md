# 三维状态标注配置说明

组件位置：**精选组件 → 场景元素 → 三维状态标注**。

**一个组件默认显示一张标注，多行文字共用背景。** 需要单独选择、调整的标注，分别拖入组件；同一组件内也可用“新增卡片”批量配置。

## 1. 添加和定位

1. 先用“内置加载器”加载三维场景，再拖入标注组件。
2. 在“热点选择”中选择卡片，再输入热点名称或 UUID 搜索。列表仅显示当前场景的热点；选择后 UUID 自动填写，卡片底部对齐热点，可调整“上方间距”。
3. 没有热点时，在“三维位置调试”中点击“在模型上拾取位置”，再点击模型表面。

旋转相机检查位置。画布拖动只调整样式调试位置，三维位置通过热点或拾取设置。设计态显示当前卡片，预览／发布态显示全部卡片。

## 2. 配置文字

在“卡片内容”中编辑：

| 配置项 | 示例 |
| --- | --- |
| 文案／变量值 | 直接填固定文字，或点击变量图标绑定 `this.state.value1` |
| 前置文字 | `温度：` |
| 单位 | `℃` |

变量值为 `25` 时，显示 **温度：25℃**。文字变量与背景状态可以绑定不同的数据。

默认自动排列，删除文字行后卡片随内容收缩。需要把文字放到图片指定位置时，选择“进阶设置 → 文字排版 → 自由定位”，再调整每行的位置；此模式保留固定高度。

**调整图片大小：直接修改“标注尺寸”的宽度、高度。** 设置高度后使用固定尺寸，图片铺满卡片；透明图片没有默认蓝色底板。单张标注也可以通过样式面板的宽高调整。

## 3. 直接使用后端颜色

原有 WS 返回的是对象数组，例如：

```js
// 概览页 overviewAlarmList
[{ name: 'x12', color: '#9364bd' }]
// 厂房页 floorAlarmList
[{ name: 'F1', color: '#2386b7', count: 0 }]
```

交付 schema 已按 `name` 查找每个标注的数据，无需配置状态值：

- **背景颜色／绑定 color**：概览 X12 使用 `this.getAlarmLabelColor(0, 'X12')`；厂房 F1 使用 `this.getAlarmLabelColor(1, 'F1')`。其他标注替换名称即可。
- **默认颜色（未连接）**：初始灰色 `#808080`，无颜色数据或 WS 断开时使用。交付 schema 已绑定 `this.state.alarmLabelDefaultColor`，可在 JS 中用 `this.setState({ alarmLabelDefaultColor: '#666666' })` 修改；收到有效颜色后优先显示后端颜色。
- **着色外形图片（透明 PNG）**：填写外形 PNG 地址；不透明部分使用后端颜色，透明部分保持透明。未配置外形时使用矩形颜色底。
- **默认背景图片**：可选的前景图片，例如透明白色图标。只需着色外形时清空即可。
- **文字内容**：对应绑定 `this.getAlarmLabelText(0, 'X12')` 或 `this.getAlarmLabelText(1, 'F1')`，显示名称和数量，`0` 正常显示。

数组中的名称匹配忽略首尾空格与大小写，例如 `x12` 与 `X12` 对应同一标注。`buildingMarkers` 数组也已适配。以上辅助方法已包含在交付 schema 中；其他页面自行配置时，可绑定自己的取值表达式，例如 `((this.state.list || []).find(item => item.name === 'X12') || {}).color`。

只显示自己的整张图片时，清空“背景颜色”和“着色外形图片”，设置“默认背景图片”；仍可使用下面的状态换图规则。颜色模式需要透明时，颜色值填写 `transparent`。

## 4. 用状态切换背景图片

例如，在页面 JS 面板的初始 state 中加入（合并到原有 state）：

```js
state = {
  status1: 1, value1: 25,
  status2: 2, value2: 32
};
```

打开 **“状态背景图片规则”**，按顺序配置：

1. 多张卡片时，先选择“当前卡片”。
2. 点击“选择状态变量”，选择 `this.state.status1`；已有 `room1` 时直接选择 `this.state.room1`。
3. 在下方“图片匹配规则”中逐条添加：

| 匹配状态值 | 背景图片地址 |
| --- | --- |
| `1` | 正常图片的实际地址 |
| `2` | 告警图片的实际地址 |

**状态从 1 变成 2，图片就从正常图切换为告警图。绑定变量后，逐条规则始终保留。** 数字 `1` 和字符串 `"1"` 会自动匹配，无需手动转换；同时配置两种类型时优先匹配同类型。`false`、空字符串和 `0` 保持独立。

第二张卡片选择自己的状态变量，例如 `this.state.status2`。各卡片状态独立，默认共用这套图片规则。

- 图片需要各不相同：在对应卡片“进阶设置 → 本标注状态背景”中配置独立规则，会替代通用规则。
- 没有匹配项：使用卡片的“默认背景图片覆盖”；未填写时使用组件的“默认背景图片”。
- 替换示例图：直接设置默认图片，或在样式面板设置背景图片，都会替换默认 SVG；已配置的自定义状态图片优先显示，不会叠加。

## 5. 更新数据

按钮或页面已有的 WS 回调中，通过 `this.setState` 更新数据：

```js
this.setState({ status1: 2, value1: 32 });
```

状态和文字会分别更新。**调用 `this.setState({...})`，不要写成 `this.setState = {...}`。** 多个标注共用页面已有的 WS 连接，组件不创建连接。

## 6. 检查和旧配置处理

- 预览时检查三维位置、状态换图、文字和单位；标注可穿透模型显示。“标注层级”可调整与其他页面组件的前后关系。
- 旧版若把状态误绑到了整个规则列表，点击“用作状态变量并恢复规则”；有预览规则时会恢复，没有时重新添加匹配项。
- 旧场景保留原位置和尺寸。需要删除文字后自动收缩时，选择“自动排列”和“随文字内容收缩”。

## 7. 按视图切换标注和热点

复用页面已有的 `sceneIndex`，只新增 `floor: 0`：`0` 表示整体／拆解视图，`1 / 2 / 3` 表示具体楼层，`null` 表示管道视图。在每个标注的“显示标注层”直接绑定布尔条件：

| 标注 | 显示条件 |
| --- | --- |
| F1／F2／F3 楼层标注 | `this.state.sceneIndex === 1 && this.state.floor === 0` |
| 一楼房间标注 | `this.state.sceneIndex === 1 && this.state.floor === 1` |
| 二楼房间标注 | `this.state.sceneIndex === 1 && this.state.floor === 2` |
| 三楼房间标注 | `this.state.sceneIndex === 1 && this.state.floor === 3` |

每张标注自行决定显示条件，可自由组合多个 state 值。需要连同绑定热点一起隐藏时，开启“同步控制绑定热点”。同一组件内多张卡片时，组件的“显示标注层”保持开启，分别在“进阶设置 → 显示本标注”绑定条件。

按钮中调用 `this.setState({floor: 1})` 选择一楼；整体／拆解按钮设置 `this.setState({floor: 0})`。交付 `index.js` 已在现有按钮事件中完成更新；进入厂房或返回概览时重置 `floor`。更新此值只控制显示，不触发动画或切换三维场景。

同步在设计态、预览和发布均生效。绑定的 UUID 必须是需要控制的热点；用模型表面坐标定位时，没有对应热点可同步。交付页面已开启同步；其他旧页面的开关仍默认关闭。热点原本被隐藏或其父模型被隐藏时，仍保持隐藏；同一热点被多个同步标注绑定时，任一标注显示则保留热点。

**将条件绑定到组件内的“显示标注层”或“显示本标注”，不要绑定到高级设置的“条件渲染”。** 条件渲染为假会卸载组件，无法继续控制热点；卸载或关闭同步会恢复热点原有显示规则。

## 本版一体式标注

尺寸104×48，文案22px，小型设备图标；底板、图标和文字作为整张标注一起移动。蒙版绑定 roomLabelImage，前景绑定 roomLabelForegroundImage，颜色继续读取 roomLabelList。
