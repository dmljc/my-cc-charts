# 一体式三维标注配置

15 个标注已配置为 104×48：左侧小型机柜，右侧 22px 文案，底部箭头对齐热点。外围背景透明。

| 配置 | 101 示例 |
| --- | --- |
| 着色外形图片 | this.state.roomLabelImage |
| 默认背景图片 | this.state.roomLabelForegroundImage |
| 背景颜色 | this.getRoomLabelColor('101') |
| 默认颜色 | this.state.alarmLabelDefaultColor（绿色） |

两张图片均已内嵌在 state，无需上传。第一张是状态色蒙版，第二张是深色底板和白色小图标；不要清空默认背景图片。

roomLabelList 的 name/color 继续控制各自的徽标、边框和箭头颜色；文字保持白色。图片与文字独立，文案仍可绑定变量。尺寸、字重和间距已统一。

需要让 101 变红：this.setState({roomLabelList:[{name:'101',color:'#e11d2e'}]})。

热点、显隐条件、底部对齐、管道 WS 和模拟入口沿用前包。现场已有的热点 UUID、动画和布局，请保留后再合并 schema。
