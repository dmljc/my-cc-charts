# 管道流动控制

在组件库「场景元素」中拖入 **管道流动控制（PipeFlow）**，与「内置加载器」放在同一页面。

交付页面已将 `data` 绑定到 `this.state.pipeFlowList`。后端发送 `pipeFlowList: [{name:"guan1_Flow", status:1}]`，`1` 流动、`0` 停止。`init_data` 为全量，`ws_data` 按名称合并增量；完整结构见 [WS 管道字段说明](pipe-flow-ws.md)。默认等待真实数据，调试面板仍保留“开始模拟 WS／推送一次”。手动模拟时收到新的真实管道数据会自动退出模拟，停止模拟会恢复最近的绑定数据。

1. **管道名称数组**：直接粘贴完整 JSON 数组并点击「应用名称数组」。默认已填入当前工程的 9 个流动模型名，包括 `guan4_Flow2`。
2. **从当前场景导入**：先将加载器切换到管道所在场景，再点击导入。默认查找 `QYguan` 开头的分组，也兼容 `QYquan`，只导入带贴图的模型。
3. **定时模拟 WS**：开启后打开预览，默认每 2 秒随机让约一半管道流动。预览面板也可开始／停止模拟、推送一次或全部停止。
4. **U/V 方向速度**：单位是 UV/秒，默认 U 为 `0.2`；负值反向。停止时可选择冻结或回到起点。
5. **流动更新频率**：默认跟随场景。300 条管道可选「30 FPS（节能）」，减少贴图更新开销，流动速度不变，不影响相机和场景渲染频率。状态切换会额外结算尚未更新的位移。
6. **流动时高亮**：按需开启，配置高亮颜色和强度。流动的管道亮起，停止后恢复原外观，不需要另绑状态变量。通常使用材质自发光；没有自发光属性的材质使用颜色高亮。高亮复用已有材质副本，不新增描边或后处理。

设计态只配置，不播放。模拟关闭后，绑定真实 state；上线时关闭「显示调试面板」。面板内修改名称只影响本次预览，持久保存请在右侧配置。

**绑定页面 state**：将「管道状态／绑定 state」绑定到 `this.state.pipeStates`，例如：

```js
{ "guan1_Flow": 1, "guan2_Flow": 0, "guan3_Flow": "1" }
```

这是完整快照：未列出的管道停止。也支持 `[{name: "guan1_Flow", status: 1}]`。状态支持 `1/0`、`true/false`、`flowing/static` 及对应字符串。

**接入增量 WS**：在现有 WS 回调中，通过组件实例调用：

```js
pipeFlow.push({name: 'guan1_Flow', status: 1}); // 只更新这一条，其余保持
pipeFlow.push([{name: 'guan1_Flow', status: 0}, {name: 'guan2_Flow', status: 1}]);
pipeFlow.setRunningNames(['guan2_Flow', 'guan3_Flow']); // 指定流动集合，其余停止
pipeFlow.stopAll();
pipeFlow.getDiagnostics(); // materials、textures、flowing、queuedMessages 等资源计数
```

名称须与配置数组、模型名完全一致；当前工程应控制 `_Flow` 模型，纯金属管体没有流动贴图。重名、未找到模型、缺少贴图／UV 会在面板提示。模型加载较慢时会自动等待 UV，超过 30 秒可点击「刷新模型」。

一个加载器自动连接；多个加载器时填写目标加载器的 `labelScope`，未设置作用域时填写其组件 ID。建议一个场景使用一个控制组件，批量控制全部管道。

高频增量消息通过 `push` 接入，同一帧内的消息合并执行，同名取最后一条，通常下一帧生效。重复状态和相互抵消的开关不执行；实际变化只处理对应名称。关闭调试面板且未配置 `onStatusChange` 时，不生成状态列表，也不因推送刷新 React。名称索引只在连接场景／刷新模型时建立。

**材质与生命周期**：首次流动时，为该模型的每个贴图材质槽创建一个材质副本；普通停止／重新启动复用它。300 条单材质管道全部用过后，缓存最多 300 个材质，不随播放时间或启停次数增加。贴图图片和几何不复制；需要改变循环采样方式时才创建采样器副本，同一原贴图和采样配置共用一个。

普通停止保留冻结位置与材质缓存。关闭「启用流动控制」、移除名称、切换场景或卸载，会释放对应材质／采样器并恢复原材质；释放时也会清空场景索引和 DOM 引用。没有流动和待处理消息时取消帧订阅；隐藏／暂停视口不更新流动。多个组件在同一视口共用帧订阅，同一模型不能重复绑定。

使用 `getDiagnostics()` 查看当前资源数量：`materials` 是运行时材质副本，`textures` 是采样器副本，`flowing` 是流动材质槽，`queuedMessages` 是本帧等待合并的名称数。普通启停后计数可以保留；关闭整个控制或卸载后应为 0。这些是组件资源计数，不等于浏览器总内存或显存。

定时模拟只创建一个定时器，关闭控制和卸载时清理。循环偏移保持有界，不播放相机或模型关键帧动画。
